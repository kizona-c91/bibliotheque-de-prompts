# NN. Titre du prompt

**Objectif :** Ce que le prompt doit produire, en une phrase.

**Quand l'utiliser :** La situation où ce prompt sert.

## Prompt

```text
Rôle : tu es [rôle].
Contexte : [situation et informations utiles, sans données personnelles].
Tâche :
1) [première étape]
2) [deuxième étape]
Contraintes : n'invente aucune donnée ; si une information manque, écris "à confirmer".
Format : [tableau, JSON, plan...].
```

## Variables à remplacer

- `[rôle]`
- `[situation et informations utiles, sans données personnelles]`

## Point de vigilance

Ce que l'humain doit vérifier avant d'utiliser la réponse.
